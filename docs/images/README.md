# Screenshots

Place your GUI screenshots in this directory.

## Recommended screenshots:

1. **Main application window** - `screenshot-gui.png`
2. **Customer management view** - `customer-view.png`
3. **Furniture inventory view** - `furniture-view.png`
4. **Order processing view** - `order-view.png`
5. **Employee tracking view** - `employee-view.png`

## How to capture screenshots:

1. Launch the application
2. Navigate to each tab
3. Take screenshots (use snipping tool, Alt+PrtScn, or Cmd+Shift+4 on Mac)
4. Save them in this directory with descriptive names
5. Update the main README.md to reference these images
